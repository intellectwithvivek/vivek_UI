Add ~40 components: AI chat, navigation, advanced form controls, DataTable, data export
and the modern/trending set. 107 exports from the core entry plus 6 charts.

- **AI chat** — `ChatMessage`, `ChatThread`, `ChatInput`, `TypingIndicator`, `ChatCodeBlock`, `Prose`
- **Navigation** — `Navbar`, `Sidebar`, `Breadcrumb`, `Pagination`, `CommandPalette`, `ScrollArea`
- **Advanced forms** — `Combobox`, `Calendar`, `DatePicker`, `FileUpload`, `OTPInput`, `Rating`, `TagInput`, `PasswordInput`, `Slider`
- **Data** — `Table`, `DataTable`, plus `toCsv` / `downloadCsv` / `printElement`
- **Modern** — `Carousel`, `Marquee`, `BentoGrid`, `AnimatedCounter`, `Countdown`, `Clock`, `RelativeTime`, `Timeline`, `Stepper`, `EmptyState`, `CopyButton`, `ThemeProvider`, `ThemeToggle`

Security fixes from a dedicated audit:

- Overlapping dialogs could leave the page permanently `inert` and `aria-hidden`, with no
  code path left to recover. Hiding is now reference counted per element.
- Link components rendered a consumer-supplied `href` with no scheme validation. React 18
  emits `javascript:` URLs verbatim (only React 19 blocks them) and `^18` is in the
  supported peer range, so CMS-fed links were a stored-XSS vector. `Footer`, `Navbar`,
  `Breadcrumb`, `Sidebar` and `Prose` now validate the scheme and add
  `rel="noopener noreferrer"` to new-tab links.
- `Skeleton` hung the main thread on a non-finite `lines`; `ChatThread` could be crashed
  by an extra key in a message record.

New tokens: `--vk-color-success`, `--vk-color-warning`, `--vk-color-overlay` (previously
hard-coded, so they could not be themed), plus `--vk-z-overlay`, `--vk-toast-z`,
`--vk-modal-width-*`, `--vk-drawer-size-*` and `--vk-toast-*`.

List item types (`Feature`, `PricingPlan`, `Testimonial`, `FaqItem`, `Stat`, `Logo`) now
accept an optional `id` for the React key. The fallback keys on a content field, which
collides on real API data and makes React mis-attach state across a reorder.
